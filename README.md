# STS2 – 6th Semester Java Practice Repository

This repository contains Java implementations of various data structures and algorithms, developed as part of the 6th Semester STS (Software Technical Skills) coursework.  
It serves as a practical resource for understanding and applying core concepts in computer science.

---

## 📁 Repository Structure

The repository includes the following Java files categorized by topic:

### 🔹 Graph Algorithms
- `BFS.java` – Breadth-First Search implementation
- `DFS.java` – Depth-First Search implementation
- `GraphBFS.java` – Graph traversal using BFS
- `GraphDFS.java` – Graph traversal using DFS
- `KahnsAlgorithm.java` – Topological sorting using Kahn's Algorithm
- `TopologicalSort.java` – Topological sort implementation
- `dial.java` – Dial's algorithm
- `Bellman.java` – Bellman-Ford shortest path

### 🌲 Tree Algorithms
- `BoundaryTraversal.java` – Boundary traversal of binary trees
- `VerticalOrderPrac.java` – Vertical order traversal practice
- `VerticalorderTraversal.java` – Vertical order traversal
- `RecoverBST.java` – Recovering a binary search tree
- `RecoverBSTpractice.java` – Practice version of BST recovery

### 🔗 Linked List Operations
- `LL1.java`, `LL2.java` – Linked list implementations
- `Detect_loop_inLL.java` – Detecting loops in linked lists
- `BitonicDLL.java` – Bitonic doubly linked list

### ⛳ Heap and Priority Queue
- `K_ary.java` – K-ary heap implementation
- `KaryHeapUsingPriorityQueue.java` – Simulating K-ary heap using Java's PriorityQueue

### 📦 Stack and Queue
- `MInStack.java` – Stack with minimum element retrieval
- `StockSpan.java` – Stock span problem solution

### 📌 Miscellaneous
- `Celebrity.java` – Celebrity problem
- `SortArray.java` – Array sorting
- `OddEven.java` – Segregation of odd and even numbers
- `WinnerTrees.java` – Winner tree implementation
